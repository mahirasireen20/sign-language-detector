# Sign Language Detector

## Real Time Sign Language Detection and Voice Output System

This project detects hand signs in real time using a webcam and converts the detected signs into voice output.

## Technologies Used

- Python
- OpenCV
- MediaPipe
- Text-to-Speech (TTS)

## Project Files

- `sign_language_detector.py` – Main Python source code
- `Sign_Language_report.pdf` – Project report

## How to Run

1. Install Python.
2. Install the required libraries.
3. Connect a webcam.
4. Run `sign_language_detector.py`.

## Features

- Real-time hand gesture detection
- Sign language recognition
- Voice output
- Supports one-hand and two-hand gestures
